## B. Audit du système 3D

1. **Le défaut de cadrage n'est pas un problème d'échelle.** Le modèle mesure environ 65 m, comme l'édifice. Il est masqué par l'extrusion OpenStreetMap de Saint-Basile lui-même : le filtre `within` n'agit pas sur les polygones des tuiles vectorielles. **Correction :** repérer les bâtiments OSM remplacés par nos modèles grâce à leur identifiant de tuile et les exclure par `["!=", ["id"], …]`. Au passage, poser chaque modèle sur le centroïde de son emprise OSM plutôt que sur les coordonnées Wikipédia.
2. **Un calque par objet, un moteur par scène : ça ne passe pas à l'échelle.** On passe à un seul calque three.js dans MapLibre, qui porte un registre d'objets. Chaque objet a sa propre ancre et son propre repère, pour ne pas perdre de précision en coordonnées Mercator.
3. **Une scène = un monument.** On passe à « une scène = un moment du voyage » : un seul monde persistant (la carte), des objets qui y apparaissent, et des environnements qui le remplacent (le métro, le train).

## D. Architecture : Scène · Portail · Destination · Trajet

```ts
type Environment = "monde" | "metro" | "train";       // ce qui remplit l'écran
type ObjectRole = "A-decor" | "B-interactif" | "C-transition" | "D-environnement";

type WorldObject = {                                   // lib/voyage/objects/*
  id: string; role: ObjectRole;
  anchor: LonLat;                                      // centroïde de l'emprise OSM
  hideOsmIds: number[];                                // bâtiments OSM remplacés
  build(): Group;                                      // géométrie procédurale, mètres
};

type Portal = {                                        // un clic = un déplacement
  verb: "Entrer" | "Découvrir" | "Voir" | "Descendre" | "Partir" | "Suivre le fleuve" | "Ressortir";
  label: string;
  to: { scene: string } | { href: string };
};

type Scene = {                                         // data/voyage/scenes.ts
  id: string;                                          // ancre : /#metro
  environment: Environment;
  title: string; ru?: string; kicker: string;          // « Moscou · jour 1 »
  camera?: { from: CameraView; to: CameraView };       // monde : interpolée au défilement
  objects?: { id: string; rise?: [number, number] }[];
  text: string; media?: string[]; placeId?: string;
  portals: Portal[];
  length: number;                                      // hauteur de défilement, en écrans
};

type Destination = { id: CityId; scenes: string[]; href: string };   // Moscou, Nijni
type Route = { id: string; mode: "metro" | "train"; from: string; to: string; line?: string; path: LonLat[] };
```

**Principe « objet → monde ».** Chaque objet fort ouvre quelque chose :
- Saint-Basile : l'objet, puis son plan vu d'en haut, puis la fiche du lieu ;
- le métro : une station, puis une ligne, puis un autre quartier ;
- la Lastochka : la gare, puis la fenêtre, puis Nijni.

**Classement des objets (6 exceptionnels plutôt que 50 moyens) :**

| Objet | Rôle | Pourquoi |
|---|---|---|
| Saint-Basile | B + C | Le plan « huit autour d'un », que la photo ne montre pas ; portail vers la place Rouge |
| Kremlin (enceinte mise en valeur sur la carte, pas de maquette) | C | Comprendre où l'on est ; portail vers Saint-Basile |
| Station de métro (environnement procédural stylisé) | D | Descendre sous Moscou |
| Rame de métro | C | Le déplacement lui-même |
| Monument aux Conquérants de l'espace | A + B | Silhouette unique, lisible de loin |
| Bolchoï, MGU | A | Repères de la ville, simples en volume |
| Moscow City | D | Les vraies tours OSM, éclairées de nuit |
| Maquette du Kremlin entier, mausolée, pont Bagration en 3D | E | Coûteux, peu lisibles à l'échelle de la carte : la carte et les photos suffisent |

## F. Nijni en relief : le kremlin sur sa falaise (30/09/2026)

**Demande.** Arrivé à Nijni, pouvoir encore défiler sur le kremlin, en 3D grandiose.

| Élément | Choix | Source · vérification |
|---|---|---|
| Relief | `raster-dem` Terrarium (Terrain Tiles, Mapzen, AWS Open Data), exagéré ×1,5 sur les scènes de Nijni seulement. L'écran le signale : « Relief exagéré ×1,5 · maquette stylisée » | Muraille entre 84 et 146 m, Volga vers 61 m : relevés sur les tuiles z15 |
| Ciel et lumière | `sky` (nuit, nuit profonde, aube) et lumière qui passe à l'est à l'aube (azimut 95°, soleil bas et orangé) | Lever du soleil fin septembre à 56° N |
| Muraille | `lib/voyage/fortress.ts` : la ligne de la muraille (contour OSM) est découpée en travées de 4 m. Chaque travée comprend la brique, un merlon et le toit du chemin de ronde, qui partagent son centroïde. Raison : MapLibre pose chaque polygone extrudé à l'altitude de son centroïde, donc un mur d'un seul tenant flotterait au-dessus de la pente | Chemin de ronde couvert et toits en bardeaux gris d'après les photos du fondateur (22/09) |
| Tours | Les 13 tours gardent leur emprise et leur hauteur OSM. Leur toit en pyramide ou en cône est fait de 7 étages, mis à l'échelle autour du centroïde MapLibre ; la hauteur du toit vient de `roof:height` quand OSM la donne. Un épi doré couronne chaque tour | OSM (ODbL), lu le 30/09/2026 |
| Parties OSM remplacées | Mur et tours OSM masqués par identifiant, seulement si toutes les parties de l'objet longent la muraille | — |
| Noms des tours | Marqueurs DOM (`lang="ru"` sur le cyrillique). Seules les 6 tours les plus proches du point visé sont nommées (3 sur mobile), au-dessus de leur toit et jamais sous le texte | — |
| Chiffres | 2,2 km de muraille (`lineKm`), 62 m de dénivelé (relief SRTM, ±10 m), 13 tours : tous affichés avec leur méthode | Tests `lib/voyage/fortress.test.ts` |

**Correctif.** Un bâtiment OSM peut être une relation en plusieurs parties, parfois éloignées les unes des autres. Or l'éclairage agit sur l'identifiant, donc sur toutes les parties à la fois. Des bâtiments de la place Minine s'allumaient ainsi avec le kremlin. Désormais, un objet n'est allumé (ou masqué) que si toutes ses parties satisfont le critère.

**Caméra.** Sur l'accueil, la nouvelle scène « La muraille descend vers la Volga » dure 3,6 écrans : depuis la Volga, puis le long de la muraille est qui dévale vers la tour Zatchatskaïa, puis au-dessus de la tour Dmitrievskaïa avec la Volga à l'horizon, puis vers la confluence. La page Nijni reprend ce parcours (3,4 écrans) avant la Strelka. Sur mobile, la caméra vise la moitié haute de l'écran, au-dessus du texte.

**Limites.** C'est une maquette : pas de mâchicoulis ni d'arcs, et les merlons sont simplifiés. La tour de l'Horloge ne garde de son étage de bois octogonal que les volumes OSM. Le Kremlin de Moscou pourrait recevoir le même traitement (merlons à queue d'aronde, toits verts) : c'est la prochaine étape logique.
